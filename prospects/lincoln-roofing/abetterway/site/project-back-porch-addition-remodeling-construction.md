Project Details
Construction Project
Lincoln, NE Homeowner wanted to add a covered backyard deck with ceiling fan. This meant pouring new footings, installing a red cedar deck, building a custom roof to extend over the porch, and installing new aluminum siding.
What We Did
Poured new footings
Installed new red cedar deck
Installed new 6×6 Cedar Post
Installed 2 LVL headers attaching to existing outside walls
Custom build roof over porch according to drawings
Installed new aluminum soffit and fascia on new roof
Installed new aluminum gutters on new covered porch
Installed new roof on entire home, including new roof portion and existing roof.
Installed new siding on gable only to match existing

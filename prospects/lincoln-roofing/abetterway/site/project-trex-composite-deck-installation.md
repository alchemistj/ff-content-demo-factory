TREX COMPOSITE DECK INSTALLATION
Project Details
Construction Project
Lincoln, NE property owners partnered with us to complete a durable, low-maintenance outdoor deck solution featuring premium Trex composite decking in the Jasper color finish. This project was completed for Buffalo Contracting and focused on delivering a clean, finished appearance with long-lasting materials and modern design details. The project included aluminum railing installation along with a picture-frame border design and matching Trex fascia for a polished look from every angle.
What We Did
Installed Trex composite decking in Jasper color
Added aluminum railing system for safety and modern style
Installed custom picture-frame deck border design
Added matching Trex fascia for a seamless finished appearance
Completed detail finishing and trim work
Final site cleanup and debris removal
Built for Beauty and Long-Term Performance
A new deck should create an outdoor space that looks great today and continues performing for years to come. Trex composite decking offers durability and reduced maintenance compared to traditional wood decking while delivering a clean, modern appearance. From precise installation to detailed finishing touches, we build outdoor spaces designed to be enjoyed season after season.
